# Solidity Learning Repository

This repository is a learning-focused collection of Solidity examples, notes, and study resources for understanding smart contract development on Ethereum.

It includes practical examples of Solidity fundamentals such as:
- boolean and integer storage variables
- signed and unsigned integers
- enums
- strings and bytes32
- payable functions and Ether transfers
- owner pattern and access control
- charity donation and self-destruct patterns

## Repository Structure

- `Notes` — learning notes covering Solidity basics and key concepts.
- `codes` — Solidity contract examples and code snippets.
- `Resources` — useful links, learning materials, and tooling references.
- `Screenshots` — visual examples related to the project.

## Topics Covered

- Solidity syntax and contract structure
- State variables and functions
- Data types (`uint`, `string`, `enum`, `address`)
- Ether handling with `payable`
- Smart contract ownership and authorization
- Transaction patterns and contract behavior

## Getting Started

You can explore the code examples directly in the `codes` folder.

For local development, you can use:
- Remix IDE for quick contract testing
- Foundry for compiling and running Solidity tests

Example commands with Foundry:

```bash
forge --version
forge build
forge test
```
